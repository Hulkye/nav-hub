# NavHub 公共页面设计规范

根据 ui-ux-pro-max 的 Marketplace / Directory 检索结果，采用蓝色编辑式探索目录设计，强化品牌首屏与搜索入口。此文件覆盖 MASTER 中与公共页面有关的配色、字体、卡片、按钮和布局建议；MASTER 保留为历史参考。

## 视觉方向

- 冷白页面、纯白内容表面、深灰文字与蓝色操作强调，灰色细分隔线组织信息。
- 首屏采用浅蓝背景与居中的搜索框，移除站点简介、品牌大标题、辅助文案与目录索引。不引入渐变、玻璃模糊或入场动画。
- 字体采用“印刷索引”：中文标题与正文使用 Noto Sans SC（思源黑体的 Noto 对应版本）；西文优先 IBM Plex Sans；数字统计、域名与快捷键使用 IBM Plex Mono；榜单编号单独使用 Noto Serif SC（思源宋体的 Noto 对应版本），宋体不用于正文或整段标题。通过 Google Fonts 加载，统一 `display=swap`，移除 CJ-gaodeguo-mh。
- 色彩通过 main.css 中的语义变量统一控制。浅色：背景 #f3f5f9，表面 #ffffff，文字 #1f2937，次要文字 #606d80，分隔线 #d8dee8，强调 #2563eb。深色：背景 #101923，表面 #172330，文字 #e5edf7，次要文字 #a8b6c8，分隔线 #344354，强调 #60a5fa。首屏使用独立的 --hero-* 语义色，深浅模式分别配对。
- 主按钮文字通过 --on-accent 配对，深色主题使用深色文字，避免浅底白字。

## 布局与组件

- 桌面头部使用白色表面、蓝色标识和圆角选中导航；投稿使用描边按钮。
- 首页搜索框居中，最大宽度 760px，窄屏自适应。统计信息只显示真实网站及分类数量。
- 桌面目录为 192px 独立分类面板与三列网站卡片；1120px 以下两列，480px 以下单列。
- 桌面分类面板撑满目录内容区域高度，不设侧栏投稿入口；移动端按分类内容自然展开。
- 网站使用 12px 圆角白色卡片、轻阴影、40px 图标容器与分隔域名行；悬停强化边框，整体链接进入详情。标题允许换行。
- 网站图标复用 SiteIcon：管理台图片 URL 优先；未配置或加载失败时，通过服务端读取网站 HTML 中声明的 favicon，并解析相对地址；无声明或读取失败时回退到 gstatic faviconV2，图片仍失败才显示首字。站点页面读取限制超时、正文大小及重定向次数，并逐跳验证公网地址。非网站内容保持封面后首字的顺序。图标已有标题说明时使用空 alt。
- 分类按钮保留 aria-pressed，数量变化通过 status 区域呈现；移动端分类自然换行。
- 移动端保留顶部展开菜单及后台配置的底部快捷导航，内容预留底部空间。

## 交互与验证

- 搜索为 GET 表单；Cmd/Ctrl + K 聚焦首页搜索框。
- 首页与搜索页共用 SearchBox 组件，统一输入框、按钮和响应式样式；支持 v-model、内容类型参数、最小输入长度以及可选快捷键。
- 链接与按钮保留键盘焦点轮廓，提供跳至主要内容入口。
- 输入框与多行文本框聚焦时不显示高亮边框或轮廓；搜索容器边框保持不变。
- 搜索页以居中搜索框为核心，内容类型使用带图标的筛选链接，不使用原生选择框。历史与热门关键词分组展示；结果采用响应式卡片，并保留即时建议、无结果推荐与分页。
- 常规控件最小高度 44px，减少误触；悬停只改变颜色，不移动布局。
- 遵循 prefers-reduced-motion；深浅主题分别检查对比度。
- 验证 375px、768px、1440px 及横屏布局，无横向溢出。

Nuxt/Vue 的响应式布局关键词未检索到有效的专项实现建议；布局实现采用 CSS Grid、媒体查询及语义 HTML 通用规范。
