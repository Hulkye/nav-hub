## 目标与范围

NavHub 首期保持架构边界：公开浏览不要求账户；后台仅系统管理员；游客投稿和评论需经过审核；内容及审核状态由服务端控制。

计划覆盖：内容管理、分类与标签、首页编排、访问与外链点击统计、投稿/评论审核完善、链接健康检查，以及必要的导入导出和前台交互增强。

不在本计划首期范围：前台账户/用户中心、第三方登录、积分/VIP/提现、支付/卡密/付费内容、AI 内容生成。此类 OneNav 能力只有在另行确认业务需求后才评估。

## 里程碑 0：内容管理基础完善

**目标**：让管理员能持续维护内容目录，而不止创建内容。

**交付范围**：
- 分类和标签的编辑、删除、层级、排序及内容关联管理。
- 内容列表按关键词、类型、状态和分类筛选，支持分页与稳定排序。
- 支持草稿、发布、下线及批量发布/下线；危险操作需要确认。
- 完善资源、书籍/影视、文章、公告等内容类型的类型化字段和校验。
- 提供内容预览和操作审计查询；写操作记录操作者、动作、对象和时间。

**验收标准**：
- 管理 API 全部独立进行管理员会话校验；无会话请求不能读取或修改管理数据。
- 草稿和下线内容不会出现在公开列表、详情、搜索、站点地图或首页模块中。
- 分类层级、内容关联和排序在编辑后正确保存；删除被引用分类/标签有明确处理规则，不产生孤儿关联。
- 列表筛选、分页总数和排序结果正确，页大小有服务端上限。
- 批量操作仅作用于明确选中的对象，失败时返回可理解结果并写入审计记录。

## 里程碑 1：首页模块编排

**目标**：让管理员能够调整首页内容结构，而不改代码。

**交付范围**：
- 管理首页模块配置：启用/停用、排序、标题、展示数量、关联分类或内容。
- 首批模块支持精选、最新、分类导航、公告等已有内容能力。
- 服务端 schema 限定模块类型、字段、数量和可关联内容范围。
- 公开首页按配置 SSR 渲染；空配置、无结果和失效关联有稳定回退行为。

**验收标准**：
- 管理员修改配置后首页顺序和展示内容正确更新，禁用模块不输出。
- 未发布内容无法通过模块配置泄露到公开页面。
- 无效模块配置被拒绝或安全降级，不导致首页 500。
- 首页模块配置 API 经过管理员鉴权，更新操作有审计记录。
- 桌面端和移动端模块可读、可操作，SSR HTML 含主要内容。

## 里程碑 2：访问与外链点击统计

**目标**：提供可信、口径清楚的基础内容热度数据。

**交付范围**：
- 对公开详情页记录访问事件，按内容类型和 ID 归档。
- 提供受控外链跳转 `/out/:id`：服务端按已发布内容 ID 读取目标 URL，记录点击后跳转。
- 管理台展示选定时间范围的访问量、外链点击量和热门内容。
- 定义事件去重、限频、保留周期与统计口径；避免收集不必要的个人信息。

**验收标准**：
- 跳转接口不接受任意 URL 参数，不允许开放重定向；草稿、下线或不存在的对象不能跳转。
- 统计写入失败不会错误地暴露内部异常或阻断正常内容浏览；可观测失败需有服务端日志。
- 机器人/短时间重复请求按明确策略去重或限频，统计接口本身不成为刷数入口。
- 管理统计的时间范围、分组和汇总数可通过固定样例数据验证。
- 不将原始 IP、邮箱等个人信息暴露在管理统计结果中。

## 里程碑 3：投稿与评论审核完善

**目标**：把游客提交类型与正式内容管理打通，并增强审核效率。

**交付范围**：
- 审核队列按状态、内容类型、日期筛选，支持分页和详情查看。
- 管理员可在审核时修订投稿字段、分配分类/标签，再批准、拒绝或标记垃圾。
- 批准时按类型创建正式网站、资源、媒体或文章内容；公告仍由管理员维护。
- 事务内记录投稿与正式内容关联，防止重复审核和重复发布。
- 评论队列提供状态筛选、详情、批准/拒绝/垃圾处理及审核历史。
- 增加重复 URL 检查、举报入口或审核提示；服务端限流及反垃圾校验持续有效。

**验收标准**：
- 待审核投稿和评论不会出现在任何公开查询中。
- 批准投稿只创建一次正式内容；并发重复审核不能重复发布。
- 每种允许投稿类型均能正确校验并映射正式内容字段；不允许任意 HTML。
- 联系方式和审核备注只对管理员可见；日志不包含不必要个人信息。
- 审核操作具备审计记录；无权限请求不能读取队列或执行审核。

## 里程碑 4：链接健康检查

**目标**：识别失效外链并支持安全的人工运营处理。

**交付范围**：
- 对已发布网站及资源外链执行手动检查，后续再支持受控定时任务。
- 保存检查时间、状态码/结果类别和脱敏错误摘要。
- 管理台支持失败链接筛选、重试、忽略和批量处理。
- 限制并发数、请求超时、重定向次数及响应体读取；默认只需要检查响应头。

**安全要求**：
- 防止 SSRF：拒绝本机、私网、链路本地、保留地址及非 HTTP/HTTPS 协议。
- 每次重定向都重新解析并验证 DNS 解析结果及目标地址，防止重定向或 DNS 重绑定绕过。
- 不向目标站发送 Cookie、Authorization 或内部请求头。
- 任务只能从数据库中已发布内容读取 URL，不接受调用者提交任意目标 URL。

**验收标准**：
- 本机/私网地址、非 HTTP(S)、超时和重定向循环按预期拒绝或记录失败。
- 检查任务可重试且限速，不阻塞正常 API 请求。
- 检查结果与内容 ID 关联；忽略项不会被常规批次反复检查。
- 管理操作经过鉴权并留审计记录。

## 里程碑 5：导入导出与批量维护

**目标**：降低初始建站和日常维护的人工成本。

**交付范围**：
- 管理员导出指定内容类型的 CSV/JSON，字段白名单化并处理公式注入。
- 支持模板化批量导入、逐行校验、重复 URL/slug 检查和错误报告。
- 导入默认进入草稿或待确认状态；显式确认后才能发布。
- 导入批次可追踪，重复执行有幂等策略或明确的冲突提示。

**验收标准**：
- 导出只包含管理员有权查看的字段，不导出会话令牌、密钥或不必要个人数据。
- 非法行不会静默丢弃；错误报告指出行号和字段原因。
- 导入过程不会绕过 schema、状态机、URL 安全规则及审计。
- CSV 公式前缀被安全处理；上传文件大小和行数有上限。

## 里程碑 6：前台交互增强

**目标**：在无用户账户前提下，补充导航站常见发现与互动能力。

**交付范围**：
- 站点举报及管理员举报处理队列。
- 轻量点赞或匿名互动计数，包含防重复、限流和反滥用策略。
- 可选的本地收藏，仅保存在访问者浏览器，不建立服务端用户档案。
- 内容分享、RSS 或更多标签聚合能力，依据实际运营需求取舍。

**验收标准**：
- 匿名互动不能伪装成账户级永久状态，文案清楚表达数据范围。
- 举报内容默认不公开，管理员可处理并留下审核记录。
- 互动接口不可用于任意内容探测、刷量或跨站请求攻击。
- 不因新增互动引入会员、积分、付费或用户画像能力。
